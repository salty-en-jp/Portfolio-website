03 / WORKS

01

WEB APPLICATION / PYTHON

Educational Video Creator

動画学習の効率を上げたかった、動画学習管理システム

つくったもの

自宅PCで動かしてLAN内の端末から動画教材で学習できるプロトタイプを制作。 再生位置をサーバー側で管理し、シークによる飛ばし見や極端な倍速などを検知、実際に視聴した区間を記録します。 オリジナル教材のアップロードや字幕の追加、動画途中にクイズを挿入することが可能です。 スマホで撮った動画一本あれば、字幕とクイズ付の動画教材を作ることが出来るアプリです。

PythonFastAPIWebSocketJavaScriptUvicorn

工夫したこと

  • 5秒ごとのハートビートによる再生位置管理
  • 視聴済み区間を基準にした修了判定
  • 動画途中のクイズと不正解時の巻き戻し
  • ログイン・管理者画面・コンテンツ管理

結果

スマホで撮影した動画をPCの指定フォルダに置くだけで、LAN内の端末から視聴できるところまで完成させました。 ログイン・アカウント管理、字幕ファイルの追加、GUIからのクイズ作成など、基本的な機能はすべて動作しています。

学び

教材を自分で撮影したため、自分自身の学習にはあまりつながりませんでした。 仕組みが動いても、教材の中身と使う人がそろわなければ学習効果は生まれない、ということを実感しました。 次は他の人に使ってもらい、教材側の課題も確かめたいと考えています。

03

WEB APPLICATION / JAVASCRIPT / AI

Elevator Talk

「セリフの型があれば、英語を話し切れるか」を確かめる、英語スピーキング練習ツール

きっかけ

帰国後、「なんか英語で言ってよ」と言われるたびに困った一方で、劇や歌ならセリフが自然に出てきました。 そこから「話せないのは単語を知らないからではなく、場面とセリフがないからではないか」という仮説を立て、 考案中の英語サークル企画の「エレベータートーク」と「違和感チェック」を土台に作りました。

つくったもの

テーマごとにセリフの型を3段階（3つ／1つ／なし）で出し、30〜60秒のタイマーの間に話し切る練習ができます。 入力はキーボード・スマホの音声入力・マイクの文字起こしに対応。 AI（Gemini）が「よかったところ」と「改善ポイント」を返し、改善ポイントは自分専用の違和感チェック問題として出題されます。

JavaScriptWeb Speech APIGemini APICloudflare WorkersGitHub Pages

工夫したこと

  • 宝探しの反省（教えすぎると暗記ゲーム、知らないと理不尽ゲーム）から、型の数をレベルで調整できるようにした
  • マイクが使えない環境でも使えるよう、キーボード入力を基本にした
  • APIキーを守るため、Cloudflare Workers で中継し、自分のサイト以外からの呼び出しを拒否
  • 記録や自分のまちがいは、ブラウザの中だけに保存

これから確かめること

サークルのメンバーに使ってもらい、型がある場合とない場合で「話し切れた」割合がどう変わるかを記録して、仮説を確かめます。

VOLUNTEER / EDUCATION

保育園 キラここキッズ軽井沢

自然の中での遊びと学習の両立を目指す保育園で、ボランティアスタッフとして学校帰りの小学生に英語を教えました。 森のようちえんでの経験と英語教育の2つの面からアドバイスし、教材とテーマを考えて、子どもたちと一緒に学びを深めました。 「今のやり方の何が合っていないのか」「この年代の子どもにはどうすれば良いのか」を考え続けた、初めての実践の場です。

考案・実践した教材のひとつが「英単語の宝探し」です。「英語を流し続けるだけで身につくのか？」という疑問から、 体を動かしながら単語に出会う形にしました。リンゴや木などの絵カードを部屋に隠し、全員が戻ってから、見つけたカードの英語名を当てます。 まず見つけた子が答え、外れたら全員が早い者勝ちで答えるルールにして、適度な競争とごほうびが生まれるようにしました。

実践してみると、期待したほどの効果は得られませんでした。事前に単語を教えすぎると暗記ゲームになり、教えなければ答えようのない理不尽なゲームになってしまいます。 一回きりのゲームではなく、日々の学習と長い期間つなげて続けることで効果が出るものだと考えています。 ゲームは続けながら、年齢を問わず通じる、より良い学び方を探しています。
