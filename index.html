01 / ABOUT

できることを増やしながら、
考えたものを確かめようとしています。

Webアプリケーションやゲーム、スマートフォン向けアプリなどを主にバイブコーディングで制作してきました。 「何のために作るのか」「どうすれば実際に使えるのか」を 考えながら実装することを大切にしています。

01

WEB APPLICATION / PYTHON

Educational Video Creator

動画学習の効率を上げたかった、動画学習管理システム

自宅PCで動かしてLAN内の端末から動画教材で学習できるプロトタイプを制作。 再生位置をサーバー側で管理し、シークによる飛ばし見や極端な倍速などを検知、実際に視聴した区間を記録します。 オリジナル教材のアップロードや、動画途中にクイズを挿入することが可能です。
