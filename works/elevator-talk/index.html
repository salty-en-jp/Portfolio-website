Elevator Talk

エレベーターが1階から5階に着くまでの30〜60秒で、テーマについて英語で話し切る練習です。
セリフの型を手がかりに、まずは最後まで話すことを目指します。

塩田 颯（さいたまIT・WEB専門学校 プロジェクトマネージャー専攻）の作品です。「セリフの型があれば、英語を話し切れるか」という仮説を確かめるために企画しました。制作の背景を見る
上の「違和感チェック」タブでは、不自然な英語を見抜くクイズができます。

送信した文章は外部のAIサービス（Google Gemini）に送られます。個人情報は入力しないでください。

AIフィードバックの例

lately i'm into vibe coding

lately i've been into vibe coding

最近ずっとハマっていることを表すには、現在完了進行形を使うとより自然です。

直された文は「違和感チェック」に、自分専用の問題として保存されます。
