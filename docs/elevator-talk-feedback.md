# Elevator Talk 検証の記録

仮説：**場面とセリフの型があれば、とっさに英語を話し切れる。**

お願いの内容：レベル1（型3つ）とレベル3（型なし）で1回ずつ話し、どちらが話しやすかったかを一言もらう。
回答者の名前は伏せる（このリポジトリは公開されているため）。

| B | | | |

## 読み取り（暫定）

回答が1人分なので、まだ結論にはしない。

- **型の量**：「型があるほうが話しやすい」という単純な結果ではなく、「相手の知識によって、ちょうどいい型の量が違う」という答えだった。レベルを3段階にした設計には意味がありそう
- **テーマとのずれ**：AIへの指示は文法と自然さだけを見ていて、テーマに沿っているかは見ていない

## 改善案（回答が出そろってから実装する）

途中で直すと、回答者によって試した版が違ってしまうため、回答が出そろってから（遅くとも 2026-11-16 の KPI 期限の後に）まとめて直す。

テーマから外れた文章を弾くのではなく、**外れ具合を見えるようにして、戻し方を教える**。

| AIの判定 | 表示 |
|---|---|
| テーマどおり | いつもどおりのフィードバック |
| 少し逸れている | フィードバック＋「テーマにつなげる一文を足すと、もっと伝わります」 |
| テーマと関係ない | 最初に「テーマから外れています」と表示し、テーマに戻す一文の例を出す（例：*Speaking of food, my favorite is …*）。文法のフィードバックはその下 |

必要な作業：

- ツール側（`works/elevator-talk/app.js`）：判定結果の表示を追加する
- Worker 側（`tools/feedback-worker/worker.js`）：AIへの指示と返す形（`topic_fit` など）を変える。変更後、Cloudflare の管理画面でコードを貼り直してデプロイする（本人の作業）
